# Collection

8 players in The Mansion. Start with fists, find 10 hidden gold stars, then cash them in at the shop on the front lawn. First to cash in wins. A Godot 4.7 rebuild of the Collection mode from imok 1v1.

- **DESIGN.md**: what's being built (the spec).
- **CLAUDE.md**: rules for AI agents working in this repo.

Open in Godot: Import → select `project.godot` in this folder.
